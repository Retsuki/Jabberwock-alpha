## 摘要

<a id="user-flow"></a>
## 用户流程

从任务标题栏启动调查。Planner 将调查分配给 Worker。Worker 选择 HTTP 操作、证据片段和隔离的离线分析，观察结果后继续或报告。用户查看工具历史、追加指令或停止 Worker。

<a id="execution"></a>
## 执行

每次 HTTP 操作校验已保存范围、支持的操作限制、DNS 结果、重定向目标和剩余请求预算。非只读方法或认证操作需要明确保存的许可及操作批准。未知限制会拒绝执行。原生内置工具保持禁用。仅当操作系统隔离能强制禁止网络及访问所有者秘密时才提供命令，不回退到不受限制的执行。

HTTP 输入示例为 `{"url":"http://127.0.0.1:43188/api/invoices?id=lab-invoice-2","method":"GET"}`。结果标识已捕获证据、实际 URL、状态与有限响应片段。工具输入、结果和失败均持久保存。发现引用已捕获的响应证据，不将推断当成漏洞。

<a id="acceptance"></a>
## 验收

通过实际桌面界面调查合成环回应用，验证模型选择的多次操作、证据支持的发现、范围外拒绝、操作拒绝、预算、取消及旧历史。并行调度和作为权威状态的共享探索图属于其他工作。
