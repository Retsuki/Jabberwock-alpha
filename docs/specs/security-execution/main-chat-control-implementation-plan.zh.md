[English](main-chat-control-implementation-plan.md) | 中文

## 摘要

> 三个阶段将普通工作区聊天连接至现有安全操作，并验证原生界面。预计涉及六至十个源码和测试文件。不计划改变数据库格式、环境变量或外部目标授权。所有者已批准 [B 方案](../../adr/0014-main-chat-security-control.zh.md)。

## 公共操作

- [x] 添加 `packages/client/ui-security/src/security-control.ts` 和 `src/control-types.ts`，提供绑定工作区的读取和经过验证的修改。
- [x] 将设置委托给 `src/index.ts` 的记录负责人，将检查项处理委托给 `src/security-setup.ts`，执行委托给 `src/security-execution.ts`，Worker 指示委托给 `src/security-workers.ts`。

- [x] 测试跨工作区标识符、过期写入、记录缺失和执行准入拒绝。

## 限制

保留原有任务和证据。不添加浏览器工具、不静默扩大范围，也不将工具接受请求视为调查完成。保留现有存储修订和重启行为。只有在验证输出存在后才能勾选验证项；本计划记录待办工作，不代表已完成结果。
