# Desktop開発 実装プラン

## 10秒サマリー

既存のクライアント監視を共通化し、Desktopの開発プロセスをまとめる。機能実装は開発ループ、任意ログインの順に進める。

## 実装順序

1. `scripts/dev-web.ts` の再利用部分を `scripts/dev-client.ts` へ分離し、既存の公開exportを保つ。
2. `scripts/dev-desktop.ts` で生成、監視、Electron起動、終了処理、ネイティブ変更時の直列再起動を管理する。
3. 開発時だけWebシェルHTMLの変更でメイン画面を再読込する。
4. `main.ts` の起動・サインアウト・失効から必須welcomeへの遷移を外す。任意のアカウント設定は残す。
5. 必要な成果物生成とアプリ起動ログを確認する。ユーザー指示によりテスト・lint・型検査は実行しない。画面確認ができなければ未確認と報告する。

## 運用

依存やビルド設定の変更は開発ループ自体を再起動する。通常のソース保存は自動反映対象。コミット・push・配布はこの作業に含めない。
