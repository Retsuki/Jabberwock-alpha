# Desktop開発と任意ログイン

## 10秒サマリー

起動中の画面変更を自動反映し、Electron・Hostの変更は再ビルド後に再起動する。初回からDeepSeekアカウントとAPIキーなしでワークスペースを開く。DB変更はない。

## ユーザーフロー

1. `pnpm run dev:desktop` で開発アプリと監視処理を起動する。
2. 画面プラグインを保存すると既存のコード再読込で反映する。WebシェルのHTML更新ではページを再読み込みする。未保存の入力や画面内だけの状態の保持は保証しない。
3. Electron・Hostのソースを保存すると監視を止め、成果物を生成して同じ開発用データで再起動する。実行中の作業がある場合はソース変更前に停止する。
4. 起動直後からワークスペースを使える。モデル提供元の認証は利用時に設定する。サインアウトや期限切れでワークスペースを閉じない。

## 仕様詳細

- WebとDesktopで監視処理を共用する。成果物生成と監視からの書込みを重ねない。
- Desktopの開発ループでは型診断なしのコンパイルとバンドルだけを行う。テスト・lint・型検査は自動実行しない。
- 既存成果物を使う場合は `pnpm run dev:desktop --skip-build`。通常起動は `pnpm run start:desktop`。
- 依存追加、ビルド設定、ルートの開発スクリプトを変更したら開発コマンドを起動し直す。native addonの変更は別途ビルドが必要。
- 設定画面の任意ログイン・API設定、モデル利用時の認証エラーを維持する。
- Host認証、独自スキーム、sandbox、contextIsolationは維持する。ファイル監視は配布アプリでは無効。
- 既存のDeepSeek向け通信や解析を全面的に無効化する変更は含まない。
