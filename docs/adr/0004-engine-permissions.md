# ADR 0004: 実行エンジンごとに権限を所有する

## 決定

Aは既存3値を全エンジンへ単純変換、Bは既存サービスとメニューを保ちながらエンジン別の保存・選択・実行変換を分ける、Cは権限サービス全体を再構築する。利用者が2026-10-17に承認したエンジン別方針に沿ってBを採用する。標準APIの独自ルールとネイティブ権限の意味を混同せず、既存の設定とコマンド導線を維持できるため。

## 責務

Agentの共有契約がネイティブ権限の許可値・既定・保存と復元を持つ。permission-presetsが表示用投影とコマンドを扱い、subscription-enginesが公式実行パラメータへ変換する。UIは現在の投影に従い、独自の権限変換をしない。

## 見直す条件

公式エンジンでモードが利用不可になった場合は選択・実行を拒否し、Full accessへ代替しない。既存投影を拡張することで複数の真実ができる場合は、独立したエンジン権限サービスへ分離するCを再検討する。
