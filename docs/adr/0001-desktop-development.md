# ADR 0001: 共通監視によるDesktop開発

- 日付: 2026-10-17
- 状態: 採用
- 決定: ユーザーがC案を承認。

## 背景と理想

画面の編集は起動中に反映し、ネイティブ処理の編集は保存された作業データを保って再起動する。監視・成果物生成・子プロセスの終了には一つの所有者を置く。

## 選択肢と決定

Aは監視とElectronを別々に手動起動。Bは既存Desktopランチャーへ監視責務を追加。CはWebの既存監視を共通モジュールへ分離し、独立したDesktop開発ランチャーから再利用する。Cを採用し、既存のHost認証と独自スキームを保つ。

## 見直す条件

画面の状態喪失が作業を妨げる場合、プラグイン単位の再読込とページ再読込の範囲を再検討する。監視中に成果物へ別のビルドを書き込む運用は禁止する。
