# ADR 0003: コンテキスト概要を既存右パネルへ固定する

## 決定

既存popoverの常設化のみのA、既存DockLayout外側に概要を置くB、右パネル全体を再構築するCを比較した。利用者のCodex風右パネル指定を受け、Bを採用する。既存のファイル・ターミナル表示と幅調整を保持し、使用量概要をタブ切替から独立させる。

## データの責務

公式エンジンはコンテキストと累積使用量のスナップショットを会話イベントに保存し、投影が最後の観測値を表示へ渡す。画面は現在の選択エンジンと一致する値だけを利用する。未取得値は空欄の理由を示し、推定と実測、累積使用量と現在コンテキストを区別する。

## 制約

Claudeのカテゴリ別カウントAPIを常時呼ばない。取得失敗は推論成功を失敗へ変更しない。Codexにない内訳やサブスク残量を推測しない。自動テストは利用者の指示に従って省略し、必要な開発用変換と起動の観測を記録する。

## 利用者による構造の訂正

カードと詳細を上下に重ねる案を撤回する。概要カードは詳細が閉じている間だけ表示し、クリックで詳細タブへ切り替える。既存sidebarのタブ機構を再利用し、会話の右余白は概要時300px、詳細時は従来の幅設定を使う。

## 配置境界の訂正

概要用のframe列は撤回する。ヘッダー全幅とチャットのスクロール境界を維持するため、conversation.contentに拡張位置を設け、同じ会話ストアを使う概要をそこへ登録する。詳細タブの所有は引き続きui-sidebar-rightとする。
