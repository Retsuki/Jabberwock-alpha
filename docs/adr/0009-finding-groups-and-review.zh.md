# ADR 0009：发现分组与规划器复核

[English](0009-finding-groups-and-review.md) | 中文

## Summary

> 已批准 B 方案：保留原始发现和证据，将重复记录关联到代表发现，并在调查边界复核已保存的执行器结果。

## Decision

Findings 负责关联和处置状态；Execution 负责预算和派发；Planning 负责结果评估。分组视图复用原始记录，不复制证据。自动关联要求匿名读取且任务、资产、方法、完整 URL、规范化标题、严重程度和原文证据均相同。用户主动分离的决定持久保存。不确定的报告在用户关联前保持独立。

A 方案只整理画面，报告统计与规划器输入仍不一致。B 方案调整现有职责并保留历史。C 方案以新事件模型替换任务协调与发现存储，扩大迁移范围但没有独立需求支撑。用户批准 B 方案。

即使 HTTP 预算耗尽，Execution 仍提交已保存的终态结果。取消、配置变更和总时限仍立即停止执行。复核上下文包含权威发现、观测、剩余预算及待执行项目。延续项目保留来源身份；同一 URL 上的无关调查不能消除其覆盖缺口。

## Reconsideration

若不同问题被自动合并，或用户处置、再测试历史被覆盖，应重新审视自动关联。若重启导致重复复核或派发，应重新审视协调机制。不得根据分组或撤回提议推断调查完成。
