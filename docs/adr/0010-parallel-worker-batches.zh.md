# ADR 0010：滚动 Worker 池

[English](0010-parallel-worker-batches.md) | 中文

## 概要

> 已批准的 B 方案在现有协调服务中加入滚动 Worker 池和不可变请求额度预留，保留原始历史与模型、工具的职责。

## 备选方案

A 仅并发启动会留下任务级状态、取消和额度问题。B 同时整理这些职责，在派发前预留额度。C 改用持久化分布式任务队列，增加本地工作流不需要的迁移与调度职责。用户批准 B，并采用 ARTEX 式空位补充。

## 决策范围

每个 Worker 在准入前取得有限 HTTP 额度。出现空位时立即领取下一项调查，无需等待其他 Worker。只有操作清理完成后才归还未使用额度。准入按任务串行，执行和控制按运行隔离。任务取消阻止排队准入，终止并等待所有操作完成。重启不回放预留记录。现有 Planner 审查使用已结束结果；重要发现或失败阻止后续派发，等待现有操作结束。

## 重新评估

额度重复分配、清理无法等待或取消后仍准入时重新评估。分布式调度需要独立设计。
