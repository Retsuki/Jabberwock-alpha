# ADR 0015：共用订阅用量与上下文显示

[English](0015-subscription-quota-context.md) | 中文

## 摘要

用户批准方案 B 及 Claude 风格的位置：复用现有上下文详情，在下方增加订阅窗口，并从输入框上下文圆环打开详情。[规格](../specs/context-sidebar/subscription-quota-spec.zh.md)定义用户可见语义。

## 备选方案

| 方案 | 结构 | 权衡 |
| --- | --- | --- |
| A | 各界面独立查询原生用量 | 重复实现刷新、账户身份及失败处理。 |
| B，已批准 | 共用账户读取与现有 Session 上下文投影 | 保持账户限制与会话占用独立，无需替换任何现有负责人。 |
| C | 替换全部上下文与用量测量 | 重写现有 Session 事件及提供方计数，范围显著扩大。 |

## 决定

订阅引擎负责有时限的只读提供方观测；右侧面板与输入框复用现有上下文投影。账户窗口是提供方观测，不是本地计算的 token 配额。提供方无法报告时，不推测额度。账户观测不进入 Session 持久化或模型输入。

## 重新评估条件

若多账户同时使用需要超出现有认证连接的身份信息，或提供方要求新认证或持久账单存储，应重新评估服务划分。不得用 token 转额度估算或任意检查会话来隐藏这些变更。
