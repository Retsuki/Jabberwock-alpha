# ADR 0011：Worker 执行期间的 Planner 审查

[English](0011-live-planner-review.md) | 中文

## 概要

> B 方案在现有任务协调器中分离池结算与 Planner 决策。工具、范围校验和总额度保留原有职责。所有者已授权实施。

## 备选方案

A 在批次循环中增加完成回调，会重复审查和停止职责。B 分离现有职责，保留服务、存储和任务历史。C 替换为跨主机持久化事件队列，增加当前本地应用不需要的恢复与部署职责。选择 B。

## 决策范围

Worker 清理结束后将不可变结果排入审查，其他 Worker 继续运行。每个任务最多运行一个 Planner。审查期间暂停派发，新结果排入下一次审查。新计划替换尚未派发的队列。运行中的调查继续归属原执行，直到结束或以经校验的运行标识明确取消。省略项目不代表取消或完成。

清理结束前保留 HTTP 预留；准入前重新计算可用额度。快照区分实际消耗、预留与当前可用额度。终局决策、超时、范围变化和用户取消等待相关操作结束。重启不自动执行；明确继续时从持久化尝试和成功审查重建尚未审查的结果。

## 重新评估

重复审查、推理期间遗漏结果或清理前归还额度时重新评估。跨主机执行需要独立调度设计。
