# ADR 0008：安全 Worker 工具

[English](0008-security-worker-tools.md) | 中文

## 摘要

用户批准具有明确操作范围的工具型 Worker，保留现有任务存储、界面与模型选择。

## 目录

- [决策](#decision)
- [重新评估条件](#reconsideration)
- [开发备注](#dev-note)

<a id="decision"></a>
## 决策

所有者批准 B 方案：保留任务存储、界面与模型选择，将单次观测执行改为有范围限制的工具型 Worker。A 方案重复执行循环；C 方案重建无关的规划与持久化。原生提供方仅接收显式注册的宿主工具。原生内置工具保持禁用；安全执行所属服务在返回结果前检查范围、操作限制、截止时间与证据。

<a id="reconsideration"></a>
## 重新评估条件

如果提供方公开未注册工具、发现无法关联捕获证据，或命令执行能绕过网络限制，必须重新评估该设计。禁用受影响能力，不回退到不受限制的执行。
