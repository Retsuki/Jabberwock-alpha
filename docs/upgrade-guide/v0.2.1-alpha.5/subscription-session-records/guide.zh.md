# 订阅引擎会话记录

[English](guide.md) | 中文

## 变更

Jabberwock 将原生会话所有权、用户明确授权的历史引导文本和工具活动分别记录为 `engine/session`、`engine/bootstrap` 和 `engine/activity`。原生上下文和累计令牌快照以 `engine/usage` 保存，供侧边栏读取。各引擎权限选择以 `engine/permission` 保存；缺少选择时使用手动批准默认值，不应用从分支父会话继承的权限。标准 API 权限设置保持独立。当前构建仍可读取已有会话。旧版本对包含这些未知必需记录的会话拒绝读取，避免静默丢失原生会话标识或授权上下文。

## 迁移

1. 如需返回旧版本，请在使用订阅引擎之前备份 Harness 主目录。
2. 使用包含订阅引擎事件目录的构建恢复这些会话。重新打开应用后确认所选引擎和会话记录仍可访问。
3. 不要手动删除引擎记录以让旧版本接受会话。降级时使用备份。
