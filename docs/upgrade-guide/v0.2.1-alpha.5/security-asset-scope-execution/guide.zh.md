# 按资产范围执行安全调查

[English](guide.md) | 中文

## 变更

新调查捕获 `targetMode: asset-scope` 以及已保存任务资产与范围规则。Planner 在此范围内选择支持的匿名 GET URL；启动表单不再要求单个 URL。Host 校验仍拒绝排除目标、非公共地址及不支持的操作。没有此模式的旧执行快照保持精确目标限制，不改写也不自动恢复。

## 迁移

1. 启动新调查前，在概览检查任务所选登记资产、范围规则及诊断许可。若未授权整个根域范围，请登记更窄的资产或排除项。
2. 从 Planner 启动新调查以使用已保存资产范围。旧精确目标执行保留为历史；重启应用不会恢复它们。
3. 确认执行显示捕获的资产、上限及所选操作。不支持的自然语言限制仍阻止执行；本次变更不启用 Shell、凭据、重定向或查询参数。
