# 本地安全实验应用

[English](README.md) | 中文

## 摘要

运行使用虚构数据的刻意脆弱应用，评估 Jabberwock 的诊断、证据、报告和复测能力。每个目标在本地运行，并独立管理依赖与生成状态。这些夹具是本地评估示例，不是部署模板。

## 目标

| 目标 | 应用 | 版本 |
|---|---|---|
| [NORTHLINE](northline/README.zh.md) | 带客户与管理员账户的 Next.js 电商网站 | 仅脆弱版；无修复版 |

NORTHLINE 已完成基础功能验证。尚未针对该目标运行 Jabberwock 诊断、依据报告修复或复测。[验证记录](../../docs/specs/security-execution/ec-lab-verification.zh.md)记载了已完成的检查。

## 评估流程

1. 按目标 README 启动应用。
2. 在 Jabberwock 中登记本地服务与测试凭据。
3. 诊断目标，并检查报告和证据。
4. 根据确认的发现修复同一个应用。
5. 复测，并将观察结果与原始证据比较。

## 目录归属

每个目标在 `benchmarks/security-labs/` 下拥有独立目录。其 `app/` 目录负责提供服务的应用与运行状态；其 `evaluation/` 目录负责位于服务目标之外、仅供评估人员使用的预期结果与测试辅助工具。不要将评估答案提供给诊断模型。新增其他应用类型时，应提供完整目标及其运行说明和验证证据。
